# Data provenance

The records were collected through OpenAQ API v3 from providers associated with public air-quality monitoring systems in Brazil, Argentina, and Chile. The repository includes the exact CSV snapshots used in the proof of concept.

The processed dataset contains 64,734 records. PM2.5 is available from eight stations, but only six stations contain enough observations to enter the predictive pipeline; therefore, results must not be interpreted as national network estimates.
