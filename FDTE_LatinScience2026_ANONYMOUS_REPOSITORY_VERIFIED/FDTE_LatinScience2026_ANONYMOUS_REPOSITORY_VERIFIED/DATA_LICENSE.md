# Data license and provenance

The files under `data/` were derived from measurements made available by providers integrated into the OpenAQ platform. The applicable license may vary by original provider and must be checked in the API metadata.

- OpenAQ API v3 overview: https://docs.openaq.org/about/about
- OpenAQ licenses resource: https://docs.openaq.org/resources/licenses

The repository preserves the exact files used in the proof of concept for academic audit. Any redistribution or downstream use must respect source attribution and the terms of the original data provider.
